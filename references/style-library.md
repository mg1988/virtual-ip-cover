# 风格库（已实测出图，持续扩充）

每期先按内容从这里选，不许只会一种。已验证风格（2026-10-10，均以码农人物或小兽出过成品）：

1. **撕纸概念海报**：斜铺撕纸承载面+蓝图桌边角、藏青巨字两段式+橙笔刷压线、红数字嵌数据行、人物右幅1/3抓纸互动。适合方法论/干货长文。已出 5:2、2.35:1、3:4。
2. **极简大字（浅色）**：米白留白+细框、人物缩到右下角点赞、三色封顶。适合连载系列攒识别、稳重题。
3. **夸张直球（黄底撞色）**：芥末黄+藏青斜切、人物半幅指镜头举红旗、标题白描边、黑底黄字胶囊数据行。适合教程、工具、要强点击的题。
4. **聊天框风**：浅灰聊天界面打底、巨型黄气泡装标题黑字、人物下半幅拿手机指气泡。适合聊天截图类、社交话题、轻松题。注意数据行必须收进气泡内，不许压气泡边框。
5. **复古报纸风**：旧报纸版式、粗黑规则线、人物半调照片框、红印章点缀、标题黑字红数字。适合盘点、历史感、严肃干货。
6. **深色极简（夜读）**：深墨绿哑光底、米白巨字+红线、人物右下小幅仰望标题区、红印章。适合深度长文、夜晚发布、沉稳题材。
7. **硬核数据截图**（未实测）：须用户给真实后台/结果截图才启用，禁止编数据、禁止生成假截图。
8. **深色终端科技风**：炭黑编辑器底+虚化青绿代码流光+点阵、细青边框、米白巨字青线、人物被屏幕光照亮抱发光笔记本。科技感最强，适合工具/代码/Agent 类；注意暗色小图先天吃亏，标题必须亮色巨字+边框兜住，不许紫蓝全息塑料感。
9. **浅色产品 UI 风**（Linear/Raycast 气质）：米白底+上方悬浮磨砂玻璃卡装标题、细灰边软阴影、人物指向玻璃卡。高级克制、和教程可信度最搭，适合产品测评/工具横评/默认脸候选；科技感靠版式不靠发光，别堆 UI 小件。

选用原则：同一选题默认出 2 个不同风格给用户挑；系列默认脸一旦选定，连出 5 期不换风格。风格之间只借语法，不混搭元素（聊天框不配撕纸、报纸不配黄气泡）。
