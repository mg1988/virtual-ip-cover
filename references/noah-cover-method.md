# 诺鸭封面方法论（沉淀版）

来源：诺鸭船长 @noahduck283《如何做出一个好封面：从入门到榨干》，2026-10-09 发布于 X。
本文件只存方法摘要与执行参数，不存原文全文。

## 一句话

封面决定长文能否在信息流零点几秒的滑动里被点开。好内容输在没有直给价值承诺，是最常见的死法。爆款三要素：选题、标题、封面。

## 四大流派（选封面打法时四选一）

1. **夸张动作 + 直球价值承诺**：人物/IP动作夸张，标题直接说收益。适合教程、干货、工具类。
2. **名梗 / 聊天框 / 视觉隐喻**：借经典名场面、聊天截图、日常实物隐喻玩心智。适合有梗点、反差、情绪的内容。
3. **极简排版 + 长期一致性**：大面积留白、巨型文字、固定版式攒识别复利。没审美把握时的安全牌，也是长期主义打法。
4. **硬核数据 + 结果截图**：收益/后台/99+消息等结果截图秀肌肉。数字必须真实可溯，没真数据禁用此派。

## 三大死穴（交付前自检）

1. **小字贪多**：封面不是目录页，一眼读不完就等于没写。小字只留一行副标以内。
2. **廉价 AI 塑料感**：全息投影、粒子、数据流、光滑塑料渲染一眼假。改走印刷海报/纸张/扁平插画质感。
3. **元素乱斗无焦点**：全场只能有一个主焦点，其余元素降级为背景层或删掉。

## 两个取舍

- **IP 绑定三路径**：真人出镜（信任感强）/ 虚拟IP（可规模化、本 skill 默认）/ 大热点时去IP贴合热点借势（别让IP挡了热点的路）。
- **放下傲慢**：尊重注意力规律，封面只负责勾人进正文，不负责讲完道理。

## 执行参数（来自其高级概念海报提示词逻辑）

- 按词义做视觉转译：先把标题拆成可画的实物/动作，再构图，不堆抽象概念。
- 巨型文字作骨架：文字是主视觉锤，嵌入画面层次（被主体轻微遮挡、压在前中景之间），不是贴在图上的标签。
- 极简承载面：背景用纸张、纯色、简单场景承载，不用复杂场景抢戏。
- 配色 2-4 色克制，高对比；重点词用单色色块标签突出（黄底黑字或红字标注）。
- 核心内容置于中心约 60% 安全区；关键元素距四边 ≥10%。
- 印刷海报质感优先：颗粒、纸纹、扁平色块；拒绝光滑 3D 塑料渲染。
- 比例参考：其提示词常用 5:2 横幅概念海报；本 skill 落地到公众号/小红书时用 3:4 竖版（gbro 硬规范），参数逻辑通用。

## 本 skill 的增补（结合既往翻车教训）

- 中文一律 PIL 叠字，生图只出无字底图（生图模型写中文必错字）。
- 叠字锚点 anchor="mm"；抖音/小红书右侧按钮列区域不放关键文字。
- 交付前逐张读图验字，不过不交付；验收没真跑完不许声称已验收。
