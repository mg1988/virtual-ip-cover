# 示例出镜人物（AIGC 虚拟人设，可替换成你自己的）

这套示例用的是一个 AIGC 生成的虚拟人物。你完全可以换成自己的角色：吉祥物、虚拟人、甚至产品拟人，流程不变。

- **身份**：25 岁中国男码农（AIGC 生成的虚拟人物，非真人照片）
- **长相**：短而微乱的黑发、黑框矩形眼镜、成人面部比例、极淡胡茬（太嫩像学生、胡茬太重显老，生成时明确年龄，light stubble only）
- **服装**：深藏青连帽衫 + 藏青工装外套、红围巾、胸前小电脑徽章（无可读文字）、常抱银色笔记本电脑
- **画风**：半 3D 绘画感卡通、粗墨线、复古印刷海报质感（米白/藏青/橙/红四色）
- **参考图**：`examples/persona-ref.jpg`（生成新封面时作为参考图输入传入，并明说保持脸型、眼镜、发型、服装不变）
- **动作库**：抓纸边往外扯（横幅）、指向上方标题区（竖版）、指镜头（直球风）、角落点赞（极简风）。动作必须和标题区发生关系，不站桩。
- **一致性提醒**：生图模型不能保证绝对同脸；脸漂移明显就用参考图重生，不硬交付。想把人物钉死，建议先做一套正式角色资产（三视图 + 表情表）再进生产。
